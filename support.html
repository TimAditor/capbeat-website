Get an answer twice as fast

CapBeat can package up what went wrong on your machine. It takes ten seconds and saves us both a round of "which version are you on?"

Step 1

Open the panel

In Premiere Pro: Window → Extensions → CapBeat, then open the System tab and scroll to the Support block at the bottom.

Step 2

Hit "Create support package"

One click collects the log and diagnostics into a ZIP on your desktop. Prefer plain text? Copy log puts the same thing on your clipboard.

Step 3

Attach it

Drop that ZIP into your email. It contains versions, error messages and processing steps — no video, no audio, no transcript, and no licence key.

Six things worth checking first

Worth thirty seconds before you write — these come up most often.

On install

Windows shows a blue warning

Normal for any young installer without a paid certificate. Click More info → Run anyway. We're buying the certificate as sales allow.

First start

It seems to hang

On the very first run CapBeat downloads the speech model once — a few hundred megabytes. It only happens once. Leave it be and let it finish.

Transcript

Wrong language detected

Auto-detect listens to the opening of your clip. If it starts with music or silence it can guess wrong. Pick the language by hand in the dropdown and run again.

Songs

Words missing from lyrics

Sung vocals need Music mode, not normal transcription. It separates the vocals from the mix first, which takes longer but catches whole verses that plain speech recognition drops.

After reopening

Captions say "Media offline"

Older versions rendered into a temporary folder that Windows clears out. Since 0.9.25 captions land in a CapBeat Captions folder next to your project file. Update, then render again.

Export

No Media Encoder installed

You don't need it any more. CapBeat exports audio on its own and splits long sequences into pieces automatically. Just make sure you're on the current version.
