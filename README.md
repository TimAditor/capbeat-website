# getcapbeat.com

Website for **CapBeat** — a Premiere Pro plugin for word-by-word captions
that also works on music, thanks to built-in vocal separation. Runs 100%
locally on your machine.

**https://getcapbeat.com**

- Free tier: full recognition quality, no watermark, videos up to 10 minutes
- Pro (€79 one-time): music mode, all styles, 19 drop-in animations, SRT export

This repository hosts the static site (GitHub Pages) and the release
downloads. The plugin itself is closed source.
